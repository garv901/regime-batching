Phase 1c · Pass D · State machine

A refused request is parked, not re-sent

MSTAR_SCHED_PARK, default off. Before: every scheduler pass re-sends every queued request to the KV gate, which refuses it again. After: a refused request is parked and not re-sent until the pool's admission-state key changes. Verdict: helps AC mode when the queue is long (530–605 requests), harmless otherwise.
