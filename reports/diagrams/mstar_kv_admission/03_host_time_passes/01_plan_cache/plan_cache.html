Plan cache: read one cached row per request, not every stream

MSTAR_KV_PLAN_CACHE, default on. The planner keeps one cached row per admitted request and updates only the rows that change. Decisions are identical and each one costs less CPU, but end-to-end latency did not move. Verdict: keep on by default, no measurable E2E gain.
