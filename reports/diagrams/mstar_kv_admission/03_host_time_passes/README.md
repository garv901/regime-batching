# Phase 1c: host time and KV release passes (C, D, E)

Reading order: 01, 02, 03. Phase 1c (branch `garv/admission-peak-backfill`) attacks host time per step and KV release timing; each pass has an env toggle. Colors are consistent: the accent (orange) marks the one focal element of each diagram, and grey or dashed marks the old (before) behavior. All numbers are measured; each diagram names the CPU bench or GPU run behind them.

1. `01_plan_cache/plan_cache.html` - Architecture delta, before / changes / after. Pass C (`MSTAR_KV_PLAN_CACHE`, default on): the planner reads one cached row per admitted request instead of re-reading every KV stream on each decision. Decisions are identical (2,700,000 checked) and one reserve decision at 64 reserved drops 450 us to 150-200 us on the CPU bench, but end-to-end latency is unchanged (0.93x-1.01x). Focal: the cached rows.
2. `02_park_queued_requests/park_queued_requests.html` - State machine of one queued request. Pass D (`MSTAR_SCHED_PARK`, default off): before, a refused request returns to Queued and is re-sent every pass; after, it is Parked until the pool's admission-state key (reserved epoch, free pages, owner-change count, queue epoch) changes. A 900-request scan drops 1.2-2.5 ms to ~115 us and short E2E on AC mode improves 0.67x on burst_v2, with no effect on peak fit. Focal: the Parked state.
3. `03_release_kv_at_completion/release_kv_at_completion.html` - Sequence over Client, Conductor, Worker (KV pool), with an ALT frame for flag off versus on. Pass E (`MSTAR_KV_RELEASE_AT_COMPLETION`, default off): RELEASE_KV frees the pages at completion, before the client reads, so p99 KV free lag falls 494 ms to 145 ms on burst_v2, but E2E is unchanged because completed requests held only 0.2-0.3% of the pool. Costs one extra message per request. Focal: RELEASE_KV.

Each folder holds the source `.html` (open it in a browser), an exported `.svg` (diagram only, without the page header) and a 2x `.png` preview. The PNG was rasterized with `rsvg-convert` on a machine without the Geist and Instrument Serif fonts, so it uses fallback fonts. Use the `.html` or `.svg` for final figures.
